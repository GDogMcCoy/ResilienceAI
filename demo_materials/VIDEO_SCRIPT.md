## SCREEN RECORDING SETUP

### Pre-Recording Checklist
- [ ] Close all unnecessary applications
- [ ] Set display resolution to 1920x1080
- [ ] Disable notifications (Do Not Disturb)
- [ ] Clear browser cache/history
- [ ] Test audio levels
- [ ] Prepare query text (copy-paste ready)

### Recording Software Options
1. **OBS Studio** (Free, recommended)
2. **ScreenFlow** (Mac, $149)
3. **Camtasia** ($249)
4. **Loom** (Free tier available)

### Optimal Settings
- **Resolution:** 1920x1080 @ 60fps
- **Codec:** H.264
- **Bitrate:** 8-12 Mbps
- **Audio:** 48kHz, 192kbps AAC

---

## VOICEOVER RECORDING

### Tone Guidelines
- Professional but approachable
- Confident, not arrogant
- Enthusiastic about impact
- Measured pace (150 words/minute)

### Technical Specs
- Use quality microphone (Blue Yeti or equivalent)
- Record in quiet environment
- Use pop filter
- Normalize audio to -16 LUFS

### Backup Plan
If voiceover recording fails:
- Use text overlays with background music
- Add captions for accessibility
- Keep screen recording as primary focus
